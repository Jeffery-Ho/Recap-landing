# Recap Landing Page v1

目标：让拍了很多照片、却很少回看的 iPhone 用户理解 Recap，并通过公开 TestFlight 邀请加入测试。英文默认，简体中文切换。参考 Nowdex 的简短主张、产品展示、隐私和 FAQ 结构。

## 已完成

- [x] 独立 Astro、TypeScript、原生 CSS 静态项目。
- [x] 英文 `/` 与中文 `/zh/`，对应语言的隐私、条款及素材来源页。
- [x] 首屏主张、每周回顾、城市回忆、主题发现，以及三个辅助能力的说明。
- [x] 真实 App 图标、双语首页、周回顾与城市目录截图；主题区采用来源可查且不重复的 Unsplash 照片面板。
- [x] 默认显示“测试邀请准备中”；全站测试链接统一配置。
- [x] 不承诺全 App 离线、云同步、万能识别或自动视频；明确本地助手和 Absolute 限制。
- [x] 原生 FAQ、键盘焦点、减少动态效果、图片尺寸、响应式 WebP、图片延迟加载。
- [x] 标题、描述、canonical、hreflang、分享预览、sitemap、robots 与 404。
- [x] Cloudflare Pages 构建配置、www 重定向、正式构建资料检查。
